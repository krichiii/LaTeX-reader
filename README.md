# LaTeX Reader

Курсовий проєкт: розпізнавання надрукованих математичних формул із зображень.
На вхід подається картинка з формулою, на виході — її код LaTeX або Markdown (`$$ … $$`).

Модель написана на TensorFlow + Keras і натренована на варіанті `full` датасету
[linxy/LaTeX_OCR](https://huggingface.co/datasets/linxy/LaTeX_OCR).

## Складові

| Папка | Що там |
|---|---|
| [`training/`](training/README.md) | модель (згорткова мережа + Transformer-декодер), завантаження датасету, тренування, оцінка, `predict` з командного рядка |
| [`backend/`](backend/README.md) | Flask API: `POST /api/predict` приймає зображення і повертає LaTeX, Markdown і впевненість моделі |
| [`frontend/`](frontend/README.md) | вебсторінка (Material Design 3): перетягнути або вставити зображення, конвертувати, переглянути формулу через KaTeX, скопіювати результат |

## Результати

Модель має 2,05 млн параметрів і тренувалась 10 епох на RTX 3050 у WSL2.
На тестовій вибірці (9 441 зображення) точний збіг становить **45,4 %**, а схожість на рівні
токенів — **0,932**. Під час розпізнавання кожне зображення читається в кількох масштабах,
і зберігається найвпевненіший результат, тому модель читає формули різного розміру.

Обмеження: тільки надруковані формули у стилі датасету (шрифт Computer Modern), одна
формула на зображення. Рукописні формули та інші шрифти розпізнаються значно гірше.

## Запуск

Найпростіше - через Docker (потрібен Docker Desktop):

```
docker compose up --build
```

Після цього сторінка відкривається на http://localhost:8080.

Без Docker: запустіть `backend/app.py` в середовищі Python 3.12 і відкрийте
`frontend/index.html`. Подробиці є в README кожної папки.
